# Mobile app (`jobblo-app/`)

- Every tappable element has pressed feedback. Tap targets are at least 44×44. Text is at least 13pt (`src/theme/textSize.check.mjs` enforces it). Use SafeArea and design down to 360px.
- Navigation uses object-form hrefs only (no template strings, no `as Href`). Every order destination goes through `src/utils/orderRoute.ts`; a provider is never sent to checkout or approval.
- Never show a raw snake_case status. Map it through the label constants.
- The API client is `src/api/client.ts` (baseURL already ends in `/api`, so paths start with `/services`, not `/api/services`). Do not create another axios instance.
- Tokens live in SecureStore through `src/utils/authStorage.ts`. The refresh token is only an httpOnly cookie. Never put a token in a deep link or log.
- Store rules: membership is never sold on iOS (App Store 3.1.1); Apple sign-in appears wherever Google does on iOS (4.8); AI use needs the consent sheet first (5.1.2).
- Feature flags are in `src/config/features.ts`. Native config (Maps keys, plugins) changes need a new native build.
- Design tokens are generated by `node design-tokens/build.mjs`. Never edit `app/global.css`, `src/theme/tailwindColors.js` or `src/theme/tokens.ts` by hand.
- Verify with `npx tsc --noEmit`, `node <file>.check.mjs` for every check file you touched, and `npx expo export` for a bundle check. Device testing is still manual.
