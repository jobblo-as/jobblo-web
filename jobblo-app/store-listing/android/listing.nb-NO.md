# Google Play store listing (nb-NO)

Copy each block into Play Console > Grow > Store presence > Main store listing.
Limits: app name 30, short description 80, full description 4000 characters.

## App name

```
Jobblo: Småjobber i nærheten
```

## Short description

```
Legg ut småjobber gratis, få tilbud fra folk i nærheten og betal trygt.
```

## Full description

```
Trenger du hjelp med flytting, maling, hagearbeid eller montering? Eller vil du tjene penger på det du kan? Jobblo kobler deg med folk i nærheten som kan gjøre jobben.

LEGG UT ET OPPDRAG GRATIS
Beskriv hva som skal gjøres, legg til bilder og velg sted på kartet. Det koster ingenting å legge ut et oppdrag og få svar. En AI-hjelper kan foreslå tittel og tekst ut fra bildene dine.

FÅ SVAR FRA FOLK I NÆRHETEN
Folk i området ditt søker på oppdraget. Se profiler og vurderinger, still spørsmål i chatten og velg den som passer best.

BETAL TRYGT MED SAFEPAY
Du betaler når du har valgt utfører, men pengene holdes trygt av Jobblo til jobben er gjort. Utføreren får betalt først når du har godkjent arbeidet. Blir dere uenige, kan du åpne en sak, så hjelper vi dere.

TJEN PENGER PÅ DET DU KAN
Finn oppdrag i nærheten, send tilbud og bygg opp gode vurderinger. Utbetalingen går rett til kontoen din når kunden godkjenner jobben.

ALT PÅ ETT STED
• Oppdrag innen rengjøring, hagearbeid, flytting, montering, maling, transport og mer
• Chat med kunder og utførere
• Varsler når noen svarer eller sender melding
• Bilder før og etter som dokumentasjon av utført arbeid
• Vurderinger etter hver jobb

Jobblo er en norsk tjeneste for småjobber. Les mer på jobblo.no.
```
