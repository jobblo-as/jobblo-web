# Phone screenshots (Google Play)

Take these on a real Android phone running the Internal testing build. The app does not run
in a web browser (native components), so they cannot be generated from code.

Requirements: 2 to 8 images, PNG or JPEG, portrait 9:16 (for example 1080 x 1920 or
1080 x 2400), no device frame needed.

Use a demo account with made-up names and jobs. Never show real users' names, chats,
addresses or payment details.

Suggested screens, in this order:

1. Hjem: the job feed with a few jobs nearby
2. A job's detail page (photos, price, place, "Søk på oppdraget")
3. Legg ut oppdrag: the photo or details step
4. Chat between customer and provider
5. SafePay: the payment overview or the "approve the job" screen
6. Profile with reviews

Save them here as 01-hjem.png, 02-oppdrag.png, ...
